# AI MOM Generator using n8n + Gemini

## Overview
This project automates meeting minutes (MOM) generation using AI. It converts raw meeting notes into structured, client-ready documentation and sends it via email.

## Tech Stack
- n8n (workflow automation)
- Google Gemini API
- SMTP Email (Gmail)

## Workflow Steps
1. Input meeting notes
2. AI processes and structures MOM
3. Converts into HTML format
4. Sends email automatically

## Features
- Automated MOM generation
- Structured output (Executive Summary, Action Items, Risks)
- Email delivery
- Ready for enterprise use

## How to Use
1. Import workflow JSON into n8n
2. Add Gemini API key
3. Configure SMTP email
4. Run workflow

## Output Example
Professional Meeting MOM sent via email
